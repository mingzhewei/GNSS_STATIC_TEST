## 协议关键事实（手册依据）
- 通用 ASCII 头（表3-18/3-19, p44-45）: `#MSG,idle,seq,0,port,time_status,week,TOW(ms),reserved,rx_status;payload*CRC32`。TOW 单位为**毫秒**。Time Status: UNKNOWN/APPROXIMATE/.../FINESTEERING。
- **设备实际存在第二种头部变体**（BESTPOSA/RANGEA/SATVIS2A）: `#MSG,port,seq,idle,time_status,week,TOW(秒),rx_status,idle_hex,msg_seq;...`，TOW 单位为**秒**，NovAtel 风格。解析时必须按字段数/首字段判别。
- BESTP（3.2.14, p85-92, ID 3020）: payload 顺序 = sol_stat, pos_type, **datum_id, reserved**, lat, lon, hgt, undulation, lat_sigma, lon_sigma, hgt_sigma, diff_age, sol_age, #SVs, #solnSVs, #solnMultiSVs, #solnL1SVs, ext_sol_stat, GPS&GLO mask, BDS mask, GAL mask, reserved, **stn_id(末尾)**。手册示例 `#BESTPA`。
- **设备实际输出 BESTPOSA 为 NovAtel BESTPOS 布局**（与手册 BESTP 不同！）: sol_stat, pos_type, lat, lon, hgt, undulation, datum, lat_sigma, lon_sigma, hgt_sigma, **stn_id(带引号, 索引10)**, diff_age, sol_age, #SVs, #solnSVs, #solnL1SVs, #solnMultiSVs, 00, 00, sig_mask1, sig_mask2。设备中无 #BESTPA 输出。
- BESTDOPS（3.2.12, p79-80, ID 3029）: payload 顺序 = **pdop, gdop, hdop, tdop, htdop**, elev_mask, #tracked, sat列表（与 NovAtel BESTDOP 的 gdop-first 顺序不同）。头部为 idle 前置变体，TOW 毫秒。更新率 ~60s 或星座变化时，非固定周期。
- IMUOBS（3.2.31, p165-168, ID 3048）: payload = imu_info, imu_type(0x81=IIM42652), week, seconds(秒,double), z_gyro, -y_gyro, x_gyro, z_acc, -y_acc, x_acc, status。Y 轴输出取负号定义。实测 ~34Hz 有效（配置 100Hz 但有周期性 ~3.1s 空洞）。
- **用户确认（2026-09-11）: M720 为纯 GNSS 模组，IMUOBS 与 INSSOLX 均不需要**。已从华测分析器中完全移除：parse_inspvaxa、6 个 chart_ins_* 图表函数、match_epochs、velocity_rms 统计、HTML/MD 报告的 INS 章节、EXPECTED_INTERVALS 中的 IMUOBSA。GUI 同步移除。INSSOLX 手册定义（3.2.33, p176-178）: ins_status, pos_type, time_since_update, lat(索引3), lon, hgt, undulation, N/E/U vel, roll/pitch/azimuth, 各sigma, ext_sol_stat —— 仅供将来参考，当前代码不再解析。
- SATVIS2A：手册无此消息名；payload 结构符合 SATINVIEW（3.2.44, p206-210, ID 3054）定义（system, vis, almanac, #sat, [prn, health, elev, az, doppler_true, doppler_apparent]×n）。
- RTKP/RTKV（3.2.42/43）布局与 BESTP 相同系（datum 在索引2）。数据中仅以**缩写 ASCII 回显**形式出现（`<RTKP ...`），非正式输出。

## 实测数据结论（RTK 文件 20260911160435）
- RTK 固定解确认：BESTPOSA pos_type = NARROW_INT×76/77（首条 NO_CONVERGENCE 启动记录），GNGGA quality=4×75。
- **基站 ID 全程恒定 "1793"**（BESTPOSA stn_id 与 GGA 末字段一致），diff_age=1.0s 恒定 → RTK 链路稳定。
- **输出丢帧严重**: BESTPOSA/GGA TOW 间隔 {1s×31, 4s×29, 5s×15, 5.5s×1}，227.5s 仅 77 条 → 按 1Hz 名义完整性 33.6%。疑似上位机/串口节流，非模组解算问题（解本身连续固定）。
- 数据污染：二进制块穿插（RTK 文件 234 行非 ASCII，SINGLE 文件 67 行）；消息拼接粘连（`#IMUOBS#IMUOBSA`、`$GNGGA...#IMUOBSA`）；CRC 校验失败 37 行（#）+1 行（$）。**采集链路存在丢字节/粘包**，需改进采集工具。
- GNGST 50 条，rms 恒定 1.823（固定解后 latσ=1.582/lonσ=1.823/hgtσ=5.196 与 BESTPOSA σ 一致）。

## 追加记录（2026-09-11 晚间）：dongtai 数据分析与解析器修正

### 数据事实（20260911174212_M720_COM11.log，3.0MB）
- 文件名带 dongtai 但实测为**静态**：水平散布 <6m 来自 3 个冷启动 SINGLE 点（1.8-5.9m），固定后 117 历元最大水平偏移 8.5mm、垂直 9.2mm
- 时长 120s（GPST 466961-467081），GGA 1Hz 完整性 100%，无数据间隙
- RTK 链路：文件内混入 RTCM3 二进制差分数据流（876 帧，类型 1074/1084/1094/1114/1124(×2)/1134 + 星历 1019/1020/1041/1042/1044/1045/1046），解析器自动跳过（约 1,001 行二进制 + 回显）
- 基站 ID 全程 "1793"；解类型 NONE×4 → SINGLE×3 → NARROW_FLOAT×1 → NARROW_INT×117
- NMEA XOR 校验 2,451 通过/1 失败（乱码行）；NovAtel CRC32 1,396 通过/0 失败；乱码行约 8-10 行（$#È° 等），占比 <0.1%
- 结果（固定解口径）：CEP95=0.56cm、水平RMS=0.21cm、垂直RMS=0.39cm、PDOP 均值 0.82、跟踪卫星平均 48 颗

### gps_rtk_analyzer_huace.py 修正（本轮）
1. **新增 get_fixed_records()**：所有静态精度指标（CEP95/RMS/峰值/散点图/时序图/HTML/MD 报告）统一只统计 SOL_COMPUTED+RTK INT/FLOAT 记录，排除冷启动 SINGLE 瞬态
2. **修复 Vertical RMS**：原代码用 
p.std(up,ddof=1) 却标注 "RMS"，改为 sqrt(mean(up²))（RMS about mean height），与 E/N 口径一致
3. **修复 generate_markdown_report 硬编码**：原 MD 报告统计表/DOP表/质量评估表/结论全部硬编码旧值（0.036m 等），改为动态计算；VDOP 在 BESTDOPSA 数据源下显示"不可用"说明
4. **validate_dop 下限 0.5→0.0**：PDOP=0.8 是多星正常值，原阈值产生 700+ 条误报；GSA 警告仅在 fix_mode>=2 时触发
5. **BESTDOPSA 补 vdop=0.0 键**（图表要求该键），HTML/MD DOP 统计优先 BESTDOPSA 与图表数据源一致
6. **位置时序图**改为固定解 ENU 偏移（米），横轴自首个固定解起算
7. **控制台摘要修正**："使用卫星数" 原为记录条数，改为平均跟踪卫星数
