# 2026-09-02

## 项目代码全面理解（GPS RTK 静态定位分析工具）

- 项目：分析北云科技(Bynav)接收机（NovAtel/ComNav 风格）静态观测 .dat 数据
- 核心文件：`gps_rtk_analyzer.py`（2834行，引擎+CLI）、`gps_rtk_analyzer_gui.py`（639行，Tkinter GUI）
- 流水线：read_dat_file → split_messages（按消息类型分文件）→ parse_* → 统计 → 17个图表 → HTML/MD 报告
- 支持消息：#INSPVAXA（INS位置速度姿态，10Hz）、#BESTGNSSPOSA（GNSS最佳解，5Hz）、$GPGGA/$GPGSA/$GxGSV（NMEA）
- 消息格式：NovAtel ASCII，`#MSG,port,seq,%idle,timing,week,tow,status,version,rslen;payload1,payload2,...*CRC`
- 关键常量：RTK_STANDARDS（固定率≥95%、CEP95 fixed 2cm/float 50cm、PDOP<2好/<3中等）、RTK_FIXED_POS_TYPES=['NARROW_INT','WIDE_INT','L1_INT',...]
- 核心 metric：llh_to_enu（WGS84 M/N曲率半径简化式）、calc_cep95、calc_2drms、fix_rate、detect_data_gaps、velocity_rms

## 已发现的代码问题（重要）

1. **generate_markdown_report 大量数值硬编码**（DOP表格、质量评估表、结论全是写死的样例数据），换数据即错误
2. chart_performance_summary 中 expected_count=actual_count=len(gnss_data)，无意义
3. GUI 后台线程直接更新 Tkinter 控件（线程不安全，代码审查报告已指出）
4. parse_gsv 把全时段数据平均成单历元，天顶图是平均快照而非时序
5. BESTGNSSPOSA 的 p_fields[19]/[20] 命名 reserved，实为 Galileo&BDS / GPS&GLONASS 信号掩码
6. 缺收敛时间分析、多路径检测、周跳检测
